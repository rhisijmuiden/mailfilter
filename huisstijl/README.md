# House style

Copy of the RHIS house style from [`rhisijmuiden/rhis-huisstijl`](https://github.com/rhisijmuiden/rhis-huisstijl) (commit `7e4805f`). That repository is the source: change the house style there and copy it here again.

- `tokens/tokens.css` and `tokens/tokens.json`: colours, spacing and radius, light and dark
- `fonts/archivo/`: self-hosted Archivo font
- `logo/`: logo, icon and favicon
- `huisstijlgids.md`: the guide (Dutch)

App rules from the guide: admin menu on the left with the logo on top, Info button at the bottom with version and updates, coral (`#FF6B57`) used sparingly for the main action.
